# 琅嬛阁

仄室藏山，一阁纳卷。

琅嬛阁是一款基于 Kotlin Multiplatform + Compose Multiplatform 的书籍管理与浏览应用，Android 是唯一维护与发布的平台；桌面 / iOS / 鸿蒙的代码保留在同一仓库，但已明确放弃，不适配、不验收、不发布。

## 平台

| 平台 | 状态 |
| --- | --- |
| Android | 唯一平台，`com.langhuan.reader`，minSdk 24 / targetSdk 36 |
| 桌面（Windows / macOS / Linux） | 已放弃，代码保留不再维护 |
| iOS | 已放弃，代码保留不再维护 |
| 鸿蒙 | 已放弃，代码保留不再维护 |

## 外观

- **12 套双色主题**：每套只有主色与辅助色两个色相，页面主体恒为白底或近黑底，强调色只落在下划线、书脊与选中态。
- **可读性校正**：文字与图标按 4.5:1 对比度自动修正，浅色主题不会出现刺眼的高饱和大面积铺色。
- **四页签**：书架 / 发现 / 本地 / 我，居中悬浮胶囊底栏，选中项带辅助色下划线。
- **3D 书架**：书脊 + 景深 + 抽书波，横向拖动吸附到整数格位，中心那本抽出显示封面，下拉更新目录；书架首页带衬线页眉与可见搜索入口，只保留这一种书架形态。
- **书籍详情**：竖屏为白底编辑式档案头，封面在左、衬线大标题与作者/字数/更新在右；内容按 `01 / 简介`、`02 / 标签`、`03 / 书籍信息` 分节，书源 / 分组 / 目录收进信息表；横屏保留模糊封面左右分栏。
- **书源体检**：书源页溢出菜单进入，支持全部 / 当前筛选、仅启用、快速 / 完整两档；结果面板给出可用 / 失效数量与原因分布，可查看、导出、批量禁用（可撤销）或二次确认删除失效源。
- **阅读排版**：底栏是全书进度条 + 上一章 / 目录 / 下一章，「排版」页签按「文字 / 段落 / 背景 / 翻页」四组排布：正文字号、字距、行距、段距，缩进、简繁、版面入口，宣纸 / 青笺 / 墨夜纸样与自定义背景，以及滚动 / 覆盖 / 仿真 / 无动画四档翻页；字体族与字重统一收进「我的 → 字体」，「更多」页签放查找、专注、书签与朗读开关。
- **衬线标题体系**：页眉、分组标题、书名统一使用衬线，正文使用系统字体。

图片源支持有限：解析链可识别图片类书源，但正文插图展示尚未完善。

## 目录结构

```
app/             Android 外壳与业务入口
ui/              共享 Compose 界面（外观改造集中在这里）
data/            数据层
core/            核心工具
foundation/      基础能力
modules/         子模块（js-api / quickjs / treeview / rjpath 等）
desktop*、iosApp、ohosApp        其它平台入口
build-logic/     Gradle 约定插件
```

## 构建

环境：JDK 21、Android SDK 37、Gradle 9.6。

```bash
# 只验编译
./gradlew -g <Gradle 用户目录> :app:compileAppDebugKotlin

# 调试包
./gradlew -g <Gradle 用户目录> :app:assembleDebug
```

Windows 下把 `./gradlew` 换成 `.\gradlew.bat`。工程路径必须是纯 ASCII，否则构建脚本会直接报错。

构建需要至少一次 git 提交（`versionCode` 由提交数推导）。正式包（R8 + 资源压缩，仅 arm64-v8a）由 GitHub Actions 在推送 `v*` 标签时构建并发布 Release，不在本地出包；日常 CI 会同时编译调试包做校验。

## 版本

### 2.7.0

- **书源体检**：新增批量体检入口与结果面板，支持全部 / 当前筛选、仅启用、快速 / 完整两档；失效源可按原因查看、导出、批量禁用（可撤销）或二次确认删除。
- **书籍详情**：竖屏改为白底编辑式档案头与 `01 / 02 / 03` 分节，书源 / 分组 / 目录改为信息表；横屏保留模糊封面左右分栏；封面按压、简介展开与标签交互统一。
- **全局外观**：新增实色主按钮与 `success / danger` 语义色，补齐 `label / meta / numeral` 排版档位；顶栏标题统一衬线，书架分组 tab 选中色渐变，校验进度条展开 / 淡入。
- **清理**：删除 3 个零引用 ScreenModel、死对话框宿主，以及未使用的文案与页面资源；中英文案各 825 条。
- **校验结果**：书源校验结束后不再只靠 toast + 自动筛选，统一改用结果面板；中途取消只统计真正跑完的源。

`versionCode = 10000 + git 提交数`（浅克隆会直接报错，需要完整历史）；`versionName` 默认取 `app/build.gradle.kts` 中的基线版本（当前 2.7.0），打 tag 时 CI 用 `-PappVersion` 注入去掉 `v` 前缀的 tag 版本，保证包内版本与 tag 一致。
