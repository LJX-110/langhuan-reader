# 琅嬛阁

仄室藏山，一阁纳卷。

琅嬛阁是一款基于 Kotlin Multiplatform + Compose Multiplatform 的书籍管理与浏览应用，Android 是唯一维护与发布的平台；桌面 / iOS / 鸿蒙的代码保留在同一仓库，但已明确放弃，不适配、不验收、不发布。

## 平台

| 平台 | 状态 |
| --- | --- |
| Android | 唯一平台，`com.langhuan.reader`，minSdk 24 / targetSdk 36 |
| 桌面（Windows / macOS / Linux） | 已放弃，代码保留不再维护 |
| iOS | 已放弃，代码保留不再维护 |
| 鸿蒙 | 已放弃，代码保留不再维护 |

## 外观

- **12 套双色主题**：白底或近黑底，强调色只落在下划线、书脊与选中态；文字按 4.5:1、辅助色按 3:1 校正。
- **四页签**：书架 / 发现 / 本地 / 我，居中悬浮胶囊底栏；书架保留 3D 书脊与抽书效果。
- **发现**：全部 / 分组 / 关键词三种筛选；当前分组单独显示，首载、无结果、加载失败各有状态。
- **阅读与排版**：字号 / 字距 / 行距 / 段距、纸样与四档翻页在「排版」；缩进、简繁、版面在「更多」；字体族、字重、界面字号统一在「我的 → 字体」。
- **衬线标题**：页眉、分组标题、书名使用衬线，正文使用系统字体。

图片源支持有限：解析链可识别图片类书源，但正文插图展示尚未完善。

## 目录结构

```
app/             Android 外壳与业务入口
ui/              共享 Compose 界面（外观改造集中在这里）
ui-model/        界面展示模型
data/            数据层
core/            核心工具
foundation/      基础能力
modules/         子模块（js-api / quickjs / treeview / rjpath 等）
desktop*、iosApp、ohosApp        其它平台入口
build-logic/     Gradle 约定插件
```

## 构建

环境：JDK 21、Android SDK 37、Gradle 9.6。

```bash
# 只验编译
./gradlew -g <Gradle 用户目录> :app:compileAppDebugKotlin

# 调试包
./gradlew -g <Gradle 用户目录> :app:assembleDebug
```

Windows 下把 `./gradlew` 换成 `.\gradlew.bat`。工程路径必须是纯 ASCII，否则构建脚本会直接报错。

构建需要至少一次 git 提交（`versionCode` 由提交数推导）。正式包（R8 + 资源压缩，仅 arm64-v8a）由 GitHub Actions 在推送 `v*` 标签时构建并发布 Release，不在本地出包；日常 CI 会同时编译调试包做校验。

## 版本

### 2.9.0

- **发现页**：可发现源按「启用 + 已配置发现分类」筛选，页头显示 `可发现 / 全部` 数量与口径说明；长按菜单与分组筛选保持不变。
- **阅读排版**：缩进、中文简繁体、版面三项从「排版」迁入「更多」，改为整行设置项；「排版」保留字号 / 字距 / 行距 / 段距、纸样与翻页。
- **字体设置**：字重、界面字号并入「字体」，三项在同一弹层里完成，不再占用我的页同级入口。
- **即时刷新**：主题 / 背景写入后先更新 Compose 外观令牌，设置页、底栏、弹窗与正文同步换色，不再依赖手动刷新。
- **底栏**：设置页改为与底栏同源的自绘图标预览；四页签固定，移除不生效的显示项与换序配置。
- **细节**：搜索历史改用紧凑胶囊；本地导入按钮文字居中、视觉高度收窄；阅读面板外部配置变更时本地状态同步。
- **清理**：删除不再使用的顺序 / 显隐配置入口与过期文档，版本号统一为 2.9.0。

`versionCode = 10000 + git 提交数`（浅克隆会直接报错，需要完整历史）；`versionName` 默认取 `app/build.gradle.kts` 中的基线版本（当前 2.9.0），打 tag 时 CI 用 `-PappVersion` 注入去掉 `v` 前缀的 tag 版本，保证包内版本与 tag 一致。
