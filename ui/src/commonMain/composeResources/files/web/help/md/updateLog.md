# 更新日志

**【温馨提醒】更新前一定要做好备份，以免数据丢失！**

## 2.1.0

- 移除书源过滤规则：搜索与发现不再按规则过滤结果，管理、导入导出与备份恢复入口一并删除，旧规则不再保留。
- 字典规则只保留阅读页长按查词与内置默认词典，管理、编辑与导入入口移除。
- 移除书源调试页。
- 正文底栏移除全书进度滑块，章节位置并入目录项显示。
- 排版设置合并为单一面板，旧的整页设置入口移除。
- 各页面异常提示统一为中文，原始错误信息仅写入日志。
- 清理无入口的书源调试页与字典规则页。
- 补齐缺失的中文资源，修正「代码视图」等未翻译文案。
- 主题定制新增辅助色，用于底栏选中项、章节进度与开关/单选描边。
- 正文底栏新增「换源」入口，长按可只换本章。
- 排版页合并本章进度，恢复默认排版移到底部。
- 3D 书架手势重做：先惯性滑行再落到格位，横向拖书架、下拉刷新与分组滑动互不抢占。
- 设置页移除解释性小字，只保留状态值与数值。

## 2.0.0

琅嬛阁 2.0.0 以核心小说闭环重新出发：书源、搜索、发现、3D 书架、正文、本地 TXT / EPUB / PDF、替换净化、换源、朗读与音频、备份恢复、主题与字号、书签与阅读记录。

- 「我的」改为外观 / 书源 / 数据 / 关于四组面板，设置行不再写解释性小字。
- 主题面板合并为「跟随系统 / 浅色 / 深色」与 12 套双色主题。
- 移除视频、漫画插件、RSS、TVBox、Web 服务、书源工具箱与规则订阅等非核心功能。
- 通知与电池优化改为系统权限或静默降级，不再弹自定义说明窗。
- 旧版本里的视频、漫画、RSS、TVBox 书籍与源默认隐藏，不会进入已移除的页面。
