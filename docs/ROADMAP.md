# 版本路线

当前发布版 `1.0.0`，下一里程碑 `2.0.0`。`2.0.0` 只做稳定性和体验收口，不扩张功能范围。

## 1.0.0 · 已发布

- 四个主页签：书架 / 发现 / 本地 / 我
- 书架 2 / 3 列封面、全部 / 在读 / 未读筛选、阅读记录入口
- 发现页立体书架、分类、换源
- 搜索多源结果按「书名 + 作者」合并
- 详情、目录、加入书架、换源
- 本地 TXT 导入（UTF-8 / GBK）
- 阅读器四种翻页、排版设置、章内查找、书签、阅读记录、进度恢复
- Legado 书源子集：CSS / XPath / JSON、POST、Cookie、Big5、`replaceRegex` 捕获组、正文清洗、健康度
- 12 套双色主题
- release arm64 APK（R8 + `shrinkResources`，自有 keystore 签名）

## 2.0.0 · 目标

### 范围

- 主题与界面打磨：页头、底栏、筛选、书脊、主题页预览；保持白 / 黑底
- 封面可靠性：实际书源封面比对；必要时补 Cookie / Referer
- 阅读器回归：翻页、进度恢复、查找高亮、首行缩进
- 发布流程：`v*` 标签自动构建签名 APK 并上传 Release
- 文档同步：README / AGENTS / ARCHITECTURE / SIGNING / 本文件

### 退出标准

- [ ] `flutter analyze` 无问题
- [ ] `flutter test` 全部通过
- [ ] release arm64 APK 可安装、可覆盖升级
- [ ] 最终真机验收：书架 / 发现 / 本地 / 我 / 搜索 / 详情 / 阅读器 / 书源 / 书签 / 阅读记录 / 明暗主题
- [ ] 连续阅读 30 分钟无崩溃、无明显内存增长
- [ ] 实际书源封面与网页一致，或已记录原因与处理
- [x] 1 条集成冒烟：导入书源 → 搜索 → 详情 → 阅读 → 记录进度

## 明确不做

- iOS、Web、桌面端
- 多 ABI、模拟器、Play Store
- 账号、社区、评论、云同步
- EPUB / MOBI / PDF 导入（本地只支持 TXT）
- 听书
- 内置书源、公开书源列表、默认仓库地址
- OTA 自更新
