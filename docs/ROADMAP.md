# 版本路线

上一发布版 `2.2.0+10`；当前版本线 `2.3.0`（本次发布：换源重构、详情零等待、发现页提速、动效地基、引擎验证线首轮；真机验证按用户决定跳过）。已发布版本与精确 build 号见 Releases。

## 2.3.0 · 本次发布

### 阅读与书源

- `text.` / `text:` 选择器与 `a.-1` 负索引（约 26 个源依赖）；滚动模式章节头补齐，四模式统一（章首大标题 + 字数/时间，章中行头）
- 引擎验证线：`engine/`（阅读引擎裁剪集）、宿主 runner 全管线（搜索→详情→目录→正文）、297 源批量体检（全链 182/297，失败全部归因）、`facade` Android 库已编译产出

### 交互与体验

- 换源重构：并发 12 + 优选分先搜 + 增量显示 + 进度/停止 + 行内切换反馈
- 详情「先推壳、页内加载」（发现 / 搜索点书零等待）；书架 / 详情去掉 DB 等待；书架移除可撤销
- 发现页提速：懒构建、保留旧列表、封面限流、并行加载；刷新按钮加载态
- 动效地基：AppMotion 词表、统一反馈组件、阅读器菜单 / 面板过渡、底栏胶囊样式与触感

### 治理

- `docs/STANDARDS.md`（目录 / 设计 / 交互 / 功能 / 代码五节统一标准）
- 文案清理（私有仓库 / 公告 / 书源管理）；移除「粘贴 JSON」入口；缓存页按书三操作；NOTICE 补 Legado（GPL-3.0）署名
