# 分阶段路线

总工期按 1 人开发估算。Phase 0 代码与构建已完成，待真机安装验证；后续阶段按顺序推进。每阶段结束必须能构建、能安装、能回滚。

## Phase 0 · 基线（代码与构建已完成，待真机验证）

范围：

- Flutter 3.44.9 / Dart 3.12.2，Android SDK 36，Java 17
- 克隆上游底本，记录提交，清理 `.git` 后重新初始化
- `备份/2026-10-21/` 保存被改/被删文件的原件
- 移除 Firebase、OTA、上游签名、公开书源仓库、上游文档与截图
- 新增「私有书源仓库」接口，不内置任何书源
- `flutter analyze` 通过，`flutter test` 60 项通过
- debug arm64 APK 可构建
- 应用名、包名、临时图标与启动图

验收：

- `flutter doctor` Android 工具链通过
- `flutter analyze` 无 error
- `flutter test` 全部通过
- `flutter build apk --debug --target-platform android-arm64` 成功
- APK 可安装启动（手机连接后验证，当前未连机）

## Phase 1 · 设计基础（2–3 天）

- 新建 design tokens：纸色、墨色、青灰、字号、间距、圆角、动效
- 重做 `ThemeData`，明暗两套
- Shell 换成档案式 header + 底部 dock
- 先改书架 / 发现两个主页
- 移除登录/账号入口，改成个人书阁页头

验收：

- 360 / 411 / 800 宽三档不溢出
- 文字缩放 1.3 不崩
- 明暗两套都能读
- 滚动 60fps（低端机默认关闭重模糊）

## Phase 2 · 发现 / 书架 / 详情 / 搜索（4–6 天）

- 书架大封面、进度、筛选/排序/多选
- 发现分类、骨架屏、换源
- 详情页编辑式布局，缺失字段降级
- 搜索按书合并，显示多源

验收：

- 空/加载/错误/无封面/无简介都有态
- 同书多源可切换
- 搜索不重复刷屏

## Phase 3 · 阅读器（5–7 天）

- 拆分 `reader_menu.dart` 为顶栏/底栏/设置 sheet/目录 sheet
- 纸张、字号、行距、段距、边距、缩进、对齐、字体
- 保留 4 种翻页
- 加章内查找；书签后续补
- 设置实时预览

验收：

- 4 种翻页无回归
- 杀进程后进度恢复
- 下载 20 章失败可重试
- 正文可查找

## Phase 4 · 引擎加固（3–5 天）

- DB 增量迁移
- Cookie
- 详情/目录/正文 POST
- Big5
- `replaceRegex` 捕获组
- 正文清洗
- 书源测试/健康度

验收：

- 固定 fixture 源全通过
- DB 升级不丢数据
- 失败源有明确原因

## Phase 5 · QA / 发布（2–3 天）

- Widget / golden 测试
- 集成测试
- 低端机性能
- 自己的 keystore
- 隐私/权限清理
- 版本号统一

验收：

- release arm64 APK 安装
- 30 分钟连续阅读无崩溃
- 无公开密钥/配置

## 明确不做

- iOS、Web、桌面端
- 多 ABI、模拟器、Play Store
- 账号、社区、评论、云同步
- 本地 TXT/EPUB 导入
- 听书
- 内置书源、公开书源列表、默认仓库地址
- OTA 自更新
