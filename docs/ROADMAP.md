# 版本路线

上一发布版 `1.0.0`；当前版本线 `2.1.1`（QA 包已构建，待真机验证后发布）。已发布版本与精确 build 号见 Releases。

## 1.0.0 · 已发布

- 四个主页签：书架 / 发现 / 本地 / 我
- 书架封面网格、全部 / 在读 / 未读筛选、阅读记录入口
- 发现页列表、分类、换源
- 搜索多源结果按「书名 + 作者」合并
- 详情、目录、加入书架、换源
- 本地 TXT 导入（UTF-8 / GBK）
- 阅读器四种翻页、排版设置、章内查找、书签、阅读记录、进度恢复
- Legado 书源子集：CSS / XPath / JSON、POST、Cookie、Big5、`replaceRegex` 捕获组、正文清洗、健康度
- 12 套双色主题
- release arm64 APK（R8 + `shrinkResources`，自有 keystore 签名）

## 2.1.0 · 已交付

### 阅读链路

- 分页器只发送标准字段并纳入引擎修订号，恢复 Rust 分页；旧进度按新页数夹取
- 目录跳章即时显示目标章节名；去掉固定等待、远跳定位、失败保留正文并可重试
- 阅读页标题只显示章节名（14sp / w500），顶部安全区按运行时刷新

### 书源与搜索

- 搜索诊断：逐源区分无结果 / 规则不兼容 / 解析失败 / 网络 / 超时；失败可单源重试
- 导入前结构校验（可只导入通过项）与单源四步测试（搜索 → 详情 → 目录 → 正文按需）
- 阶段 + 规则字段级报错；诊断 URL 去掉查询参数
- `@onclick` 与尾接 `@js:` 规则兼容；结果去重、按书名相关度排序、关键词缓存
- 并发上限（默认 6）、20s 首屏软超时与「停止等待」；按分组搜索与换源
- 换源逐源状态（候选 / 无匹配 / 失败原因）与重试

### 界面与数据

- 连续 3D 书架：有限滚动、默认聚焦最近阅读、行内删除确认；整理页 3D + 拖动排序 + 批量删除
- 发现 / 搜索封面补全（详情页补封面 + 字排占位 + 跨页缓存）
- 分卷目录（`isVolume` 分组卷头）；数据库 3→4 增量迁移（`chapters` 增卷字段）
- 12 套主题可读性审计；3D 表面全部由主题派生
- 检查更新：GitHub Releases 静默检查 + 手动入口，仅打开发布页
- 私有仓库支持 GitHub 只读 Token（仅存本机）
- 章内预取范围可配（默认前 1 后 2）

## 2.1.1 · 修复（待发布）

### 书架与记录

- 书架冷启动加载（2.1.0 缺失 `initShelf()` 调用）

- 用户可见错误按类型短文案输出，不再直出异常对象
