# 功能

琅嬛阁是个人自用的 Android 网络小说阅读器：不内置书源、不提供公开书源列表，数据只保存在本机。

## 书架

- 连续 3D 立体书架：有限滚动、默认聚焦最近阅读，书脊带景深与吸附
- 整理页拖动排序、批量删除、分组筛选；全部 / 在读 / 未读
- 标签筛选、随机抽书（尊重当前筛选）
- 书架内联搜索：按书名 / 作者过滤，空结果可转全网搜索
- 长按书脊可检查单本更新（只查本书源）；发现新章节显示「更新」角标，打开书后清除
- 移出书架可撤销（`on_shelf` 置 0，撤回即恢复）

## 发现与搜索

- 发现由书源 `exploreUrl` 驱动的平面列表，支持分类与翻页游标
- 搜索按「书名 + 作者」合并多源结果，支持关键词缓存、首屏窗口、暂停 / 继续
- 失败按源归因，可单源重试；诊断面板显示阶段、字段、规则与耗时

## 详情与换源

- 先用搜索种子推页，详情在页内加载，失败可页内重试
- 换源精搜：按书名（忽略空白）+ 作者精确匹配，同名不同书不会混入候选
- 换源并发扫描、增量显示、可停止；本地书不支持换源

## 阅读器

- 翻页：仿真 / 覆盖 / 无动画 / 纵向滚动
- 实时调整纸张、字号、行距、段距、边距、对齐与字体
- 章内查找；可切到「已缓存章节」跨章搜索（只搜本地缓存，不发网络请求）
- 书签、阅读记录、进度恢复；章节头显示字数与更新时间
- 书签跳转落点高亮：打开书签后短暂显示内容注册框
- 阅读位置锚点：记住当前页首个字符偏移，换字号 / 边距后仍回到同一段
- 简繁转换：原样 / 简体 / 繁体（正文规范化后、分页前转换）
- 专注模式、字重三档；低性能设备可关闭动效
- Android 触摸输入按屏幕刷新率重采样，翻页/拖动更跟手
- 目录：分卷、搜索、章序直达
- 离线下载：排队、暂停继续、仅 WiFi；按书清理缓存

## 本地 TXT

- UTF-8 / GBK 自动识别，按章节标题分章
- 多文件导入显示进度，解析在后台 isolate
- 长按本地书可修正书名 / 作者（只改书架显示，不改原文件）

## 书源

- 统一由 `engine/`（阅读内核裁剪集）+ `SourceEngine` 提供，只有一条实现
- 规则：CSS / XPath / JSON、POST、Cookie、Big5、替换捕获组、`@js:` 与 JS 选择器
- 导入校验、单源四步测试（搜索 / 详情 / 目录 / 正文）、批量体检、内置编辑器
- 私有仓库同步：失败不写半批；仓库地址与 Token 只存本机

## 标签

- 书籍详情底部「标签」：勾选已有标签或当场新建；未加入书架时提示先加入
- 书架顶部标签行：按标签筛选，与「全部 / 在读 / 未读」叠加生效
- 我的 → 标签管理：新建、重命名、删除（删除只移除归属，不动书籍与进度）
- 标签没有独立配色，只用主题强调色与中性色

## 替换净化

- 我的 → 替换净化：规则列表、新建、编辑、删除、启停
- 规则按顺序应用：纯文本或正则（`$1` 引用捕获组），可作用于正文 / 章节标题
- 只净化显示内容，不改写章节缓存；改动后重新打开章节生效

## 备份与恢复

- 入口：我的 → 备份与恢复
- 备份内容：书籍信息、阅读进度（含位置锚点）、书签、阅读记录、标签、替换规则；可选书源规则原文
- 不含：章节正文、分页缓存、登录 Cookie、仓库 Token、字体文件
- 导出为 gzip JSON（`.lhb`）；导入前显示数量预览
- 合并语义：本地已有的书与进度不覆盖；书签/记录取较新的一份；书源与替换规则只补缺失项；单事务失败整体回滚

## 低性能模式

- 我的 → 低性能模式：关闭书架入场动画与封面预取，减少低端机卡顿
- 不影响主题、阅读排版、分页、书源与下载；下次进入书架生效

## 外观

- 12 套双色主题，只切换强调色与辅助色；页面固定白底 / 近黑底
- 统一组件：`PageHeader`、`LoadingView`、`Pressable`、`showFeedback`
- 图标与启动图见 [BRAND.md](BRAND.md)
