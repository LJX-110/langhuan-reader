# 品牌与应用身份

已选定：**琅嬛阁**，Android 包名 `com.langhuan.reader`，Dart 包名 `langhuan`。

- 一句话：一阁藏书，只读自己带来的书。
- 应用名取自传说中天帝藏书之地「琅嬛福地」，三字、古典、有实物意象。
- 界面只保留「琅嬛阁」与自己的副题，不出现上游名称、链接、邮箱或截图。

## 品牌资产（Phase 1）

当前图标与启动图由 `tool/generate_brand_assets.py` 生成，方向 **双页书**：

- 碧海青底，冷白双页，鎏金书口与一方金印
- 1024 px 母版绘制后按密度降采样，保证各尺寸比例一致
- 输出 `assets/brand/icon_master.png`、`icon_foreground.png`、`launch_logo.png`
- 同步写入 Android 各密度 `mipmap-*/ic_launcher*.png`、自适应图标 XML、`drawable-nodpi/launch_logo.png`
- 自适应图标底色使用 `@color/brand_deep` `#14505B`
- `AndroidManifest.xml` 使用 `android:roundIcon="@mipmap/ic_launcher_round"`

重新生成：

```powershell
python tool/generate_brand_assets.py
```

母版源文件在 `assets/brand/`，不要只改 Android 产物。

## 视觉系统

### 色板

只保留五种色相：

| 角色 | 色值 | 用途 |
|------|------|------|
| 白 | `#FFFFFF` | 页面底色、卡片、搜索框 |
| 黑 | `#141414` | 主文字、线条、编号方点 |
| 青 | `#1B5C66` | 选中态、强调、书脊 |
| 鎏金 | `#C9A24B` | 印章、图标金边、书脊细线 |
| 朱砂 | `#A8483A` | 错误、更新点 |

中性灰只由黑白派生：底纹 `#F2F2F2`、分隔 `#E8E8E8`、次文字 `#4D4D4D`、说明 `#6E6E6E`。图标底使用更深的青 `#14505B`，仍属青色，不新增色相。

暗色基座为 `#0E0E0E`，表面 `#181818`，分隔 `#2A2A2A`，正文 `#F5F5F5`，强调色用 `#6FA8AE`。

页面不再使用宣纸米黄或雾青底，默认纯白。颜色定义集中在 `lib/design/tokens/app_colors.dart`；界面优先通过 `ThemeData` 取色。

### 字体与版式

- 标题使用系统宋体 `AppType.serif`，字距略放宽，保持书阁档案感。
- 正文使用系统无衬线或用户选定的阅读字体；阅读器正文由 `ReadSetting` 独立控制，不随界面主题换色。
- 页头采用档案编号式小标：`01 / 藏书`、`01 / 寻书`、`01 / 书阁`；编号后只留一条细线和一个小方点，不再加金色短横。
- 英文副题固定为 `LANGHUAN / READING ARCHIVE`。
- 鎏金只做小面积点缀：印章、图标金边、书脊细线；不做正文色，不大面积铺色。

### 界面构件

- `ArchiveBrandBar`：印章 + 应用名 + 档案副题；右侧放页面动作。
- `ArchiveLabel` / `ArchiveTitle`：章节眉标与标题；标题降到 22px，避免杂志感。
- `PaperSearchEntry`：白底、细边框的搜索入口，不再加多余说明。
- `SealMark`：界面内的小印章「琅」，金底黑字，小面积使用。
- `Bookshelf3D`：发现页顶部的立体书架，书有书脊、书页厚度、透视和落地阴影，左右可吸附。
- `LanhuanDock`：底部四页签（书架 / 发现 / 本地 / 我），白底、无胶囊、无模糊；选中只把图标和文字变青。
- 不使用重模糊或玻璃效果；header / dock 都是实色白。

## 诗句与文案

「琅嬛」本义是传说中天帝藏书的地方，也用作藏书室的美称。以下句子来自可查的原文，适合做页脚、空态或关于页的引文：

| 句子 | 出处 | 可用位置 |
|------|------|----------|
| 读书三十乘，千万中一二。 | 明·张岱《琅嬛福地记》 | 关于页、阅读统计页脚 |
| 此中有全书，并不遗只字。 | 明·张岱《琅嬛福地记》 | 书架有书时的页脚、藏书说明 |
| 深柳读书 | 明·张岱《陶庵梦忆·琅嬛福地》 | 发现页小标、空态短句 |
| 楼下门之，匾曰「琅嬛福地」 | 明·张岱《陶庵梦忆·琅嬛福地》 | 关于页、品牌故事 |

使用原则：

- 主标语仍是「一阁藏书，只读自己带来的书」，诗句只做副题或引文，不取代主标语。
- 引文必须保留作者与篇名，不把古文改成现代口号。
- 不在主界面堆砌诗句，一页最多一处。

## 包名规则

- 个人侧载，不经过应用商店；包名仍建议一次定好，后续换名需要改 `applicationId`、`namespace`、`MainActivity` 包路径和签名配置。
- 包名只使用小写字母与数字，不使用下划线。
- 如果希望和 GitHub 身份绑定，可用 `com.<github用户名>.reader`；用户名含连字符时去掉连字符。
