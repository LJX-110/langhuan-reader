# 品牌与应用身份

已选定：**琅嬛阁**，Android 包名 `com.langhuan.reader`，Dart 包名 `langhuan`。

- 应用名取自传说中天帝藏书之地「琅嬛福地」。
- 界面极简：每页只留一行页面标题，不保留品牌顶栏、英文副题或档案编号。
- 界面只出现「琅嬛阁」与自己的文案，不出现上游名称、链接、邮箱或截图。

## 品牌资产

图标与启动图由 `tool/generate_brand_assets.py` 生成，方向 **月照琅嬛**：

- 墨蓝底 `#17283A`，月白圆盘 `#F2E9D7`，一阁柔金楼阁 `#B89A68`
- 楼阁为单檐、平脊、两侧起翘；无月亮以外的额外装饰元素
- 1024 px 设计稿在 4 倍画布上绘制后按密度降采样
- 输出 `assets/brand/icon_master.png`、`icon_foreground.png`、`launch_logo.png`
- Android 自适应图标底色 `@color/brand_deep` `#0F1B2B`；每档 mipmap 还包括 `ic_launcher_monochrome.png`（Android 13 主题图标）
- 顶栏已删除，图标只用于启动器与启动页；不再出现在页面顶部

重新生成：

```powershell
python tool/generate_brand_assets.py
```

真正的母版是 `tool/generate_brand_assets.py`；`assets/brand/` 下的 PNG 是脚本产物，不要只改 Android 产物或单个密度图。

## 视觉系统

### 页面

- 浅色模式固定白底，暗色模式固定近黑底；主题不整页铺荧光色。
- 每页只有一行 `PageHeader`：左对齐页面名（书架 / 发现 / 本地 / 我的），右侧放动作。
- 不保留 `LANGHUAN / READING ARCHIVE`、`01 / 藏书` 这类小字和编号。
- “我的”是普通列表加发丝线，不用卡片、淡色图标底或 tagline。
- 空态只用左对齐短句 + 文字按钮，不用大圆图标和胶囊按钮。

### 字体与版式

- 页面标题使用系统宋体 `AppType.serif`，22px，字距略放宽。
- 正文使用系统无衬线或用户选定的阅读字体；阅读器正文由 `ReadSetting` 独立控制，不随主题换色。
- 不再使用档案编号、英文副题、金色短横和大量说明小字。
- 主题色只用于按钮、选中态、书脊、小面积标签；不做整页背景。

### 界面构件

- `PageHeader`：一行页面标题 + 右侧动作。
- `PaperSearchEntry`：白底细边框搜索入口。
- `Bookshelf3D`：立体书架组件，含书脊、书页厚度、透视与吸附；用于书架页与本地页的 3D 模式，发现页保持平面列表。全新安装默认 3D，旧版 `coverGrid` 偏好继续保留为网格 / 列表。
- `LanhuanDock`：底部四页签（书架 / 发现 / 本地 / 我），实色白、无胶囊、无模糊。
- 阅读器纸色、字体、翻页视觉保持独立。

## 诗句与文案

「琅嬛」本义是传说中天帝藏书的地方，也用作藏书室的美称。以下句子来自可查的原文：

| 句子 | 出处 | 可用位置 |
|------|------|----------|
| 读书三十乘，千万中一二。 | 明·张岱《琅嬛福地记》 | 关于页、阅读统计页脚 |
| 此中有全书，并不遗只字。 | 明·张岱《琅嬛福地记》 | 藏书说明 |
| 深柳读书 | 明·张岱《陶庵梦忆·琅嬛福地》 | 空态短句、关于页 |
| 楼下门之，匾曰「琅嬛福地」 | 明·张岱《陶庵梦忆·琅嬛福地》 | 关于页、品牌故事 |

使用原则：

- 主标语仍是「一阁藏书，只读自己带来的书」，诗句只做副题或引文。
- 引文保留作者与篇名，不把古文改成现代口号。
- 主界面不堆砌诗句，一页最多一处。

## 包名规则

- 个人侧载，不经过应用商店；包名一次定好，后续换名需要改 `applicationId`、`namespace`、`MainActivity` 包路径和签名配置。
- 包名只使用小写字母与数字，不使用下划线。
- 如果希望和 GitHub 身份绑定，可用 `com.<github用户名>.reader`；用户名含连字符时去掉连字符。
